# app/styles/ — globalne style

| Plik | Rola |
|---|---|
| `tokens.css` | Pakiet design-systemu aplikacji: deklaracje `@font-face` (self-hostowane woff2 z `/fonts/`, DM Sans / Space Grotesk / JetBrains Mono), zmienne CSS (kolory, typografia, spacing, radii) oraz bazowe style. Źródło prawdy zsynchronizowane z `design-system/colors_and_type.css` + `prototype/styles.css`. |

Importowany globalnie (przez `app/root.tsx`). Pełny opis tokenów i reguł
wizualnych: [`../../design-system/README.md`](../../design-system/README.md).
