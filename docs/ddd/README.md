# docs/ddd/ — metodyka Domain-Driven Design

Materiały o **Domain-Driven Design** dla tego projektu: metodyki, flow analizy i
notatki. Zawiera generyczny (niezależny od projektu) playbook analizy
strategicznej (`strategic-ddd-flow.md`) oraz — w podkatalogu `kalisthenos/` —
konkretne, prowadzone fazami wyniki analizy strategicznej dla kalisthenos.

## Podkatalogi

| Katalog | Rola |
|---|---|
| [`kalisthenos/`](kalisthenos/README.md) | Wyniki analizy strategicznej DDD dla kalisthenos (brownfield, kroki 1–7), prowadzonej fazami z artefaktem per faza. Wejściem jest indeks + tablica statusu; plan i runbook faz w `kalisthenos/00-plan-analizy-strategicznej.md`. |

## Pliki w tym katalogu

| Plik | Rola |
|---|---|
| `strategic-ddd-flow.md` | Pełne flow **analizy strategicznej DDD** jako generyczna metodyka (po polsku): 8 kroków wg *DDD Starter Modelling Process* (DDD Crew) spięte z kanonem (Evans, Fowler, Vernon, Brandolini, Team Topologies) — dla każdego kroku cel, uczestnicy, technika i artefakt. Plus przybornik technik warsztatowych (EventStorming, Core Domain Chart, Bounded Context Canvas…), katalog wzorców context mappingu, heurystyki i anty-wzorce. Warstwa strategiczna + krótki pomost do taktycznej. Źródła cytowane. |
