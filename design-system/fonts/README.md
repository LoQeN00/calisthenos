# design-system/fonts/ — źródłowe webfonty

Źródłowe woff2 design-systemu (DM Sans, Space Grotesk, JetBrains Mono) w
podzbiorach `latin` / `latin-ext`. Wersje serwowane przez aplikację leżą w
[`../../public/fonts/`](../../public/fonts/README.md) i są ładowane przez
`app/styles/tokens.css`. Role typograficzne: [`../README.md`](../README.md).

| Plik | Font |
|---|---|
| `DMSans-latin.woff2` / `DMSans-latin-ext.woff2` | DM Sans (tekst) |
| `SpaceGrotesk-latin.woff2` / `SpaceGrotesk-latin-ext.woff2` | Space Grotesk (display/brand) |
| `JetBrainsMono-latin.woff2` / `JetBrainsMono-latin-ext.woff2` | JetBrains Mono (liczby/badge) |
