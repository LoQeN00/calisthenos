# design-system/preview/ — statyczne karty podglądu

Statyczne pliki HTML prezentujące elementy design-systemu (tokeny, typografia,
kolory, komponenty, brand) do przeglądu w panelu podglądu. Czysta dokumentacja
wizualna — nie są częścią aplikacji. Opis systemu: [`../README.md`](../README.md).

| Grupa | Pliki |
|---|---|
| Brand | `brand-icons.html`, `brand-logo.html`, `brand-topbar.html`, `brand-voice.html` |
| Kolory | `colors-accent.html`, `colors-dark.html`, `colors-ink.html`, `colors-semantic.html`, `colors-surfaces.html` |
| Komponenty | `components-badges.html`, `components-buttons.html`, `components-card.html`, `components-difficulty.html`, `components-inputs.html`, `components-list-row.html`, `components-sidenav.html`, `components-video-ring.html` |
| Spacing | `spacing-borders.html`, `spacing-radii.html`, `spacing-shadows.html` |
| Typografia | `type-body.html`, `type-display.html`, `type-eyebrow.html`, `type-mono.html` |
| Pomocnicze | `_card.css` (wspólne style kart podglądu) |
