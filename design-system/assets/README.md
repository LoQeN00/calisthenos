# design-system/assets/ — logo i ikony

Zasoby marki design-systemu. Pełny opis brandu/ikonografii: [`../README.md`](../README.md).

| Plik | Rola |
|---|---|
| `icons.jsx` | Zestaw ikon line-style (Lucide-style, 24×24, stroke 1.75). Eksportuje `window.Icons`. Odpowiednik produkcyjny: `app/components/icons.tsx`. |
| `logo-mark.svg` | Znak marki — czarny kafelek z białym "K". |
| `logo-wordmark.svg` | Pełny lockup (znak + "kalisthenos" + limonkowa kropka) na jasne tła. |
| `logo-wordmark-dark.svg` | Wariant na ciemne tła. |

Limonkowa kropka przy wordmarku jest częścią lockupu — nieopcjonalna.
